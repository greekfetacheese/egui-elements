# <p align="center">egui-elements</p>

egui-elements is a collection of widgets and utilities for the [egui](https://github.com/emilk/egui) GUI library.

Its the successor of [zeus-theme](https://crates.io/crates/zeus-theme), [zeus-ui-components](https://crates.io/crates/zeus-ui-components) & [zeus-widgets](https://crates.io/crates/zeus-widgets).

The goal of this crate is to make it easy for people to create nice
looking apps with egui.

Theme roles, surfaces, and state mapping: [docs/theme.md](docs/theme.md).

## Demo

```bash
cargo run --example demo --features full
```
